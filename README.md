# 💰 HelpFinance - Gerenciador Financeiro Pessoal

O **HelpFinance** é uma aplicação web desenvolvida para facilitar a gestão de orçamentos pessoais de forma simples, rápida e eficiente. Com uma interface limpa e intuitiva, a ferramenta permite ao usuário registrar entradas e saídas financeiras, acompanhando o saldo total atualizado em tempo real.

---

## 🎯 Objetivo do Projeto

O principal objetivo do HelpFinance é oferecer uma solução prática para o controle do fluxo de caixa diário sem a necessidade de cadastros complexos ou conexão com servidores externos, garantindo privacidade e agilidade no acesso às informações.

---

## ✨ Funcionalidades

- 🟢 **Registro de Entradas:** Adição de receitas e ganhos de forma simples.
- 🔴 **Registro de Saídas:** Controle de despesas e custos operacionais diários.
- 📊 **Cálculo Automático de Saldo:** Recálculo em tempo real do saldo total disponível à medida que novas transações são inseridas ou removidas.
- 💾 **Persistência Local de Dados (`LocalStorage`):** Salvamento automático de todas as movimentações no navegador do usuário, mantendo os dados preservados mesmo após atualizar ou fechar a página.
- 📱 **Interface Responsiva:** Layout adaptado para proporcionar uma boa experiência de navegação tanto em desktops quanto em dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição / Aplicação |
| :--- | :--- |
| **HTML5** | Estruturação semântica da interface e formulários de entrada de dados. |
| **CSS3** | Estilização moderna, design responsivo e organização visual dos cards de saldo. |
| **JavaScript (ES6+)** | Lógica de manipulação do DOM, cálculos de fluxo financeiro e gerenciamento do `LocalStorage`. |
